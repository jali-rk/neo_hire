# Aphrodite careers site

A one-page recruitment website for Aphrodite (Pvt) Ltd: five founding roles at its Central Studio in Sri Lanka. Built with React, TypeScript and Vite, and pre-rendered to static HTML.

```bash
cd site
pnpm install
pnpm dev       # local development
pnpm build     # production build → site/dist/
```

Before publishing, set the careers inbox in `site/src/content.ts` (`CONFIG.careersEmail`).

**Taking over the project? Start with [HANDOVER.md](HANDOVER.md).** It covers decisions, status, setup, the design system and the full plan.
